# Garden Advice App

## Overview

The Garden Advice App is an interactive web application built using HTML, CSS and JavaScript.

The application allows users to select a season and plant type and receive tailored gardening advice based on their selections.

This project demonstrates front-end development fundamentals including DOM manipulation, event handling, JavaScript objects and responsive web design.

---

## Features

- Select a season from a dropdown menu
- Select a plant type from a dropdown menu
- Generate gardening advice dynamically
- Responsive user interface
- Interactive button-driven functionality
- Scalable advice system using JavaScript objects
